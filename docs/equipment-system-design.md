# 《动物大战外星人》装备系统设计文档

> 版本：v2.0 ｜ 日期：2026-11-04 ｜ 定位：深度借鉴《魔兽世界》部位体系，为「动物进化肉鸽」新增一套**零贴图、重构筑、强门槛**的装备系统。

---

## 0. 设计目标与核心原则

### 0.1 三大核心诉求

1. **深部位养成** —— 16 个部位，还原魔兽「一点点攒装备」的满足感。
2. **传说稀有化** —— 0.1% 掉率 + 一局上限 1 件，让传说成为"可遇不可求"的终极追求。
3. **三重门槛通关** —— 打赢最终 Boss 必须**好装备 + 好技能 + 好技能组合**三者齐备，缺一不可。

### 0.2 硬性约束

| 约束 | 说明 |
|---|---|
| **零贴图** | 装备不新增任何图片资源，用**人形图 + 部位着色**表现，主包体积零增加 |
| **性能优先** | 装备实体复用对象池，禁止高频 `new` / `shadowBlur` 滥用 |
| **覆盖而非抉择** | 同部位新装备**直接覆盖**旧装备，不弹对比面板，保持割草节奏 |
| **不破坏技能养成** | 装备是乘法/加法叠加到 `player` 既有属性，不重写伤害公式 |

### 0.3 现有属性挂载点（装备直接写入）

> 来自 `js/player/index.js`，装备加成只读写这些已存在字段。

```
atkMultiplier     攻击倍率        critRate       暴击率
critDmgMultiplier 暴击伤害(新增)  dodgeRate      闪避率
lifeSteal         吸血            magnetRadius   拾取半径
hpRegen           每秒回血        cooldownReduce 冷却缩减
baseSpeed         移速            maxHp          最大生命
```

### 1.2 部位分组与掉落来源

| 分组 | 部位 | 掉落来源 |
|---|---|---|
| **护甲组**（8 件） | 头/颈/肩/背/胸/腕/手/腰/腿/足 | 普通怪、精英 |
| **首饰组**（4 件） | 戒指×2 + 饰品×2 | 精英、Boss |
| **武器组**（2 件） | 主手 + 副手 | Boss、稀有精英 |

> 武器组（主手/副手）是**攻击力的核心来源**，掉率最低、价值最高，还原魔兽"拿到一把好武器"的质变感。

## 2. 稀有度体系

### 2.1 六档稀有度（还原魔兽品质感）

| 稀有度 | 颜色 | 掉率（基础） | 词条数 | 说明 |
|---|---|---|---|---|
| 粗糙 (Poor) | 灰 `#9d9d9d` | 40% | 1 | 白板过渡 |
| 普通 (Common) | 白 `#ffffff` | 30% | 1 | 基础 |
| 优秀 (Uncommon) | 绿 `#1eff00` | 18% | 2 | 主力过渡 |
| 精良 (Rare) | 蓝 `#0070dd` | 8% | 3 | 核心构筑 |
| 史诗 (Epic) | 紫 `#a335ee` | 3.89% | 3 + 1 元素 | 强构筑核心 |
| 传说 (Legendary) | 橙 `#ff8000` | **0.1%** | 4 + 1 元素 + 1 专属 | 改变玩法，可遇不可求 |

### 2.2 掉率随游戏时间演化

> 稀有度权重随时间轴推进整体上浮，但**传说始终锁定 0.1% 极低掉率**。

```
progress = gameTime / 720  (0~1)

传说：固定 0.1%（不随时间变化，保持稀有）
史诗：3.0% + progress * 2.0%   （决战期 ~5%）
精良：7% + progress * 3%       （决战期 ~10%）
优秀：18%（固定）
普通/粗糙：剩余
```

### 2.3 传说装备的特殊规则

1. **一局最多掉落 1 件传说** —— 掉落后本局 `legendaryDropped = true`，不再掉落
2. **拾取后角色显示独特隐藏造型**（见 §5）
3. 传说的专属词条是**改变玩法**级别（见 §3.3）

## 3. 装备词条体系

### 3.1 基础词条（数值型）

| 词条 key | 名称 | 类型 | 数值区间（按稀有度缩放） | 挂载属性 |
|---|---|---|---|---|
| `atk` | 攻击力 | 加法 | 3% ~ 30% | `atkMultiplier` |
| `crit` | 暴击率 | 加法 | 1% ~ 10% | `critRate` |
| `crit_dmg` | 暴击伤害 | 加法 | 3% ~ 30% | `critDmgMultiplier` |
| `hp` | 生命上限 | 加法 | 15 ~ 150 | `maxHp` |
| `hp_regen` | 每秒回血 | 加法 | 0.3 ~ 4 | `hpRegen` |
| `dodge` | 闪避率 | 加法 | 1% ~ 8% | `dodgeRate` |
| `lifesteal` | 吸血 | 加法 | 1% ~ 5% | `lifeSteal` |
| `cdr` | 冷却缩减 | 加法 | 2% ~ 15% | `cooldownReduce` |
| `move` | 移速 | 加法 | 2% ~ 12% | `baseSpeed` |
| `magnet` | 拾取半径 | 加法 | 8% ~ 40% | `magnetRadius` |
| `dmg_reduce` | 减伤 | 加法 | 1% ~ 8% | `damageReduce`(新增) |

### 3.2 元素词条（史诗及以上，与五行联动耦合）

| 词条 key | 名称 | 效果 |
|---|---|---|
| `ele_fire` | 烈焰强化 | 火系技能伤害 +8% |
| `ele_water` | 潮汐强化 | 水系技能伤害 +8% |
| `ele_wood` | 自然强化 | 木系技能伤害 +8% |
| `ele_metal` | 锋锐强化 | 金系技能伤害 +8% |
| `ele_earth` | 磐石强化 | 土系技能伤害 +8% |
| `ele_thunder` | 雷霆强化 | 雷系技能伤害 +8% |
| `ele_wind` | 疾风强化 | 风系技能伤害 +8% |

> **核心耦合点**：装备的元素词条计入 `ElementSynergyManager.collectOwnedElements`，让装备成为「补全元素羁绊」的钥匙。如玩家缺"风"元素触发「天地雷火 +35%」，一件带 `ele_wind` 的戒指即可补全。

### 3.3 专属词条（传说独有，改变玩法）

| 词条 key | 名称 | 效果 |
|---|---|---|
| `unique_berserk` | 血怒 | 生命低于 30% 时攻击 +50% |
| `unique_glass` | 玻璃大炮 | 攻击 +60%，生命 -30% |
| `unique_tank` | 磐石 | 减伤 +20%，移速 -10% |
| `unique_elec` | 电光石火 | 每次暴击触发一次闪电链 |
| `unique_vamp` | 血族 | 吸血翻倍，生命上限 -20% |
| `unique_avatar` | 神降化身 | 全身属性 +15%，并触发隐藏造型 |

## 4. 生成与掉落

### 4.1 掉落触发

> 复用 `gem.js` 掉落管道，新增 `type: 'equipment'`。

```
击杀敌人时，按概率掉落装备：
- 普通怪：2% 掉率
- 精英怪 (isElite)：12% 掉率
- Boss (isBoss)：100% 掉率（保证 1 件，武器组概率最高）
```

### 4.1.1 掉落 → 拾取 → 装备 流程（手动拾取）

> 装备掉落物**不自动装备**，需要玩家走到掉落物上手动拾取，拾取后才生效。与经验魂石/肉块/磁铁的拾取手感完全一致。

```
掉落物生成（一个稀有度色块，躺在战场地面）
        ↓ 玩家靠近（进入拾取半径 / 磁铁吸引）
手动拾取（碰撞拾取，同 gem 逻辑）
        ↓
同部位覆盖：直接替换该部位的旧装备，旧装备销毁
        ↓
立即生效：applyStats() 重算总属性 + 人形图部位换色
        ↓
（若为传说）触发隐藏造型 + legendaryDropped = true
```

**拾取细节：**
- 掉落物颜色 = 该装备的稀有度色（灰/白/绿/蓝/紫/橙），一眼可辨品质
- 掉落物受 `magnetRadius` 磁铁影响（玩家有拾取装备距离加成时更易吸到）
- 拾取后**不弹窗、不暂停**（除非是传说，传说拾取弹一次全屏金色提示），保持割草节奏
- 同部位新装备**直接覆盖**旧装备，无需对比确认

### 4.2 生成算法

```
generateEquipment(gameTime, legendDropped):
  1. 若 legendDropped，稀有度池剔除传说
  2. 确定部位（按部位权重随机；Boss 偏武器/首饰）
  3. 确定稀有度（按 2.2 权重，传说 0.1%）
  4. 确定词条数（按稀有度）
  5. 从该部位词条池随机抽取
  6. 词条数值在该稀有度区间随机
  7. 史诗 +1 元素词条；传说 +1 元素 +1 专属
  8. 若传说，置 legendDropped = true
```

### 4.3 词条数值平衡锚点

> 以「全身满配 ≈ 满配被动 + 好元素组合」为锚点，保证装备与技能**互相补充、不可替代**。

```
16 部位满配史诗 ≈ 每件 5.0 强度，全身 ≈ 80 强度
好技能组合（元素联动 +35% + 6 满级主动技能）≈ 60~80 强度

→ 单靠装备（无好技能）：~80 强度，不足以秒杀最终 Boss（4 万血）
→ 单靠技能（无好装备）：~60 强度，也差一口气
→ 装备 + 技能 + 组合（三者叠加）：~140 强度，才能稳过 Boss
```

## 5. 装备可视化：人形图 + 部位着色

### 5.1 核心原则：零贴图

装备**不新增任何图片资源**，全部用 Canvas 矢量绘制，主包体积零增加。

### 5.2 人形图布局（左下角）

```
┌────────────────────────────────┐
│                                │
│                                │
│              (战斗区域)          │
│                                │
│        ┌──────┐                │
│        │ ●头部 │ ← 有装备=着色   │
│        │ ╱╲   │                │
│        │(胸甲) │ ← 有装备=着色   │
│        │ 主手 │ ← 有装备=着色   │
│        │ ╱ ╲  │                │
│        └──────┘                │
│  ██ 16部位人形图(左下角) ██      │
└────────────────────────────────┘
```

### 5.3 着色规则（不同品质 → 不同颜色）

> 左下角人形图每个部位的颜色，直接反映该部位当前装备的**品质**。六档品质对应六种颜色，一眼可辨。

| 部位状态 | 显示颜色 |
|---|---|
| 无装备（空槽） | 灰色半透明轮廓 `rgba(255,255,255,0.15)` |
| 粗糙 (Poor) | 灰 `#9d9d9d` |
| 普通 (Common) | 白 `#ffffff` |
| 优秀 (Uncommon) | 绿 `#1eff00` |
| 精良 (Rare) | 蓝 `#0070dd` |
| 史诗 (Epic) | 紫 `#a335ee` |
| 传说 (Legendary) | 橙 `#ff8000` + 微光脉冲动画 |

> 这样玩家无需打开任何面板，只需扫一眼人形图的颜色分布，就能判断全身装备的成色（如"全身绿蓝，主手橙"）。

### 5.4 人形图交互

- 点击左下角人形图 → 展开**右侧装备总览面板**（只显示总属性）
- 人形图始终显示，战斗中不遮挡操作（半透明 + 小尺寸）

## 6. 装备效果面板（右侧）

### 6.1 布局（只显示总属性加成）

> **核心规则**：右侧面板**只显示所有装备汇总后的总属性加成**，不逐件显示每件装备的单独词条。单件装备的品质/部位信息通过左下角人形图的**部位颜色**来传达。

```
┌────────────────────────────────┐
│  战斗区域        │  装备总览(右)  │
│                  │              │
│                  │  总属性加成    │
│                  │  ┌────────┐  │
│                  │  │攻击 +45%│  │
│                  │  │暴击 +18%│  │
│                  │  │生命 +320│  │
│                  │  │移速 +12%│  │
│                  │  │回血 +3/s│  │
│                  │  │吸血 +5% │  │
│                  │  │冷却 -15%│  │
│                  │  └────────┘  │
│                  │              │
│                  │  (元素加成)   │
│                  │  火系 +8%    │
│                  │  风系 +8%    │
│                  │              │
└────────────────────────────────┘
```

### 6.2 面板内容

- **总属性加成**：所有装备词条**汇总后**的净加成（攻击/暴击/生命/移速/回血/吸血/冷却/减伤等）
- **元素加成汇总**：各元素技能伤害的总加成（火系 +8% 等）
- **不显示**：单件装备的词条明细（那部分交给左下角人形图的部位颜色表达品质）
- 点击面板外任意处 → 关闭，回到战斗

### 6.3 信息分工（关键设计）

| 信息 | 呈现位置 |
|---|---|
| 单件装备「品质」 | 左下角人形图的部位颜色（灰/白/绿/蓝/紫/橙） |
| 单件装备「词条」 | 拾取瞬间的短暂飘字提示（如"主手·精良 攻击+30%"） |
| 全身「总加成」 | 右侧装备总览面板 |

> 这样玩家日常只需瞄一眼左下角人形图的颜色分布 + 右侧总属性，即可判断装备强度，无需逐件点开看词条。单件词条只在「拾取那一刻」以飘字形式快速告知。

## 7. 传说隐藏造型

### 7.1 触发条件

拾取**传说装备**后，角色立即显示独特隐藏造型。

### 7.2 实现方式（零贴图）

> 复用现有 `modelStage.js` 的阶段模型机制，新增一个「传说造型」覆盖层。

```
拾取传说装备时：
  1. 记录 player.equipment.hasLegendary = true
  2. 渲染层检测 hasLegendary：
     - 在现有角色模型上叠加「金色能量光晕 + 粒子光环」
     - 用 Canvas 绘制金色描边轮廓（非贴图）
  3. 造型 = 现有模型 + 传说特效，不新增图片资源
```

### 7.3 造型层次

| 造型层 | 触发 | 表现 |
|---|---|---|
| 基础造型 | 默认 | 现有阶段模型（1~5 阶段） |
| 史诗造型 | 全身 ≥ 4 件史诗 | 紫色微光 |
| **传说造型** | 拾取传说装备 | 金色能量光晕 + 粒子光环 + 金色描边 |

## 8. 通关门槛设计（三重门槛）

### 8.1 核心公式

> 打赢最终 Boss = **好装备 + 好技能 + 好技能组合**，三者缺一不可。

```
最终 Boss 血量 = 40000（现有基准）

玩家 DPS 构成：
  DPS = 技能基础伤害 × 技能等级成长 × 元素联动倍率 × 装备攻击倍率

三重门槛拆解：
  1. 好技能    —— 满级技能（Lv.5/6），基础伤害高
  2. 好组合    —— 元素联动（+15%~35%）+ 6 主动技能搭配
  3. 好装备    —— 主手武器 + 全身攻击词条（攻击倍率 +40%~80%）
```

### 8.2 门槛验证（数值推算）

| 配置 | 估算 DPS | 能否击败 4 万血 Boss |
|---|---|---|
| 满级技能 + 好组合 + 好装备 | ~140 强度 | ✅ 稳过（1~2 分钟） |
| 满级技能 + 好组合，无装备 | ~60 强度 | ❌ 差一口气（磨不死） |
| 满级技能 + 好装备，无组合 | ~80 强度 | ❌ 勉强（风险大） |
| 技能未成型（无论装备） | <40 强度 | ❌ 完全打不动 |

> **设计意图**：玩家必须在 12 分钟内**同时**凑齐「技能满级 + 元素组合 + 关键装备」三件事，才能通关。任何一项缺失都会在最终 Boss 前卡住，形成清晰的养成目标。

### 8.3 与现有 12 分钟节奏的衔接

| 时间段 | 装备获取重点 |
|---|---|
| 0~120s 发育期 | 攒基础护甲（头/胸/腿），过渡到优秀/精良 |
| 120~300s 爬坡期 | 追求主手武器（攻击核心），补首饰 |
| 300~600s 割草期 | 刷精良/史诗，追求元素词条补全羁绊 |
| 600~720s 决战期 | 全身成型，若凑齐传说则质变 |

## 9. 持久化与局外

- **局内有效**：装备死亡/通关后清空，保持肉鸽"每局重新构筑"
- **传说掉落保底**：跨局累计——若连续 3 局未掉落传说，第 4 局传说掉率提升至 0.5%（避免玩家挫败，同时不破坏稀有性）

## 10. 实现路线

### Phase 1（核心闭环）
1. `js/equipment/equipment_data.js` —— 16 部位 + 6 稀有度 + 词条配置表
2. `js/equipment/EquipmentManager.js` —— 生成、覆盖、属性汇总、对象池
3. 掉落管道接入（`gem.js` 加 `equipment` 类型 + `enemy.js` 死亡掉落判定）
4. 属性写入 `player`（`applyStats` 统一汇总）

### Phase 2（可视化）
5. 左下角人形图（16 部位 Canvas 绘制 + 部位着色）
6. 右侧装备效果面板
7. 稀有度掉落光效、拾取反馈

### Phase 3（深度）
8. 元素词条与 `ElementSynergyManager` 耦合
9. 传说隐藏造型（金色光晕 + 粒子光环）
10. 传说掉率保底 + 平衡调优

## 11. 关键风险与对策

| 风险 | 对策 |
|---|---|
| 16 部位导致装备面板过挤 | 右侧面板只显示「总属性加成」，单件品质靠左下角人形图颜色表达 |
| 传说 0.1% 掉率过低挫败 | 跨局保底（3 局未掉 → 0.5%），且传说不是通关必需 |
| 覆盖机制让玩家"没得选" | 覆盖是简化设计，符合割草节奏；单件词条用拾取飘字告知，降低信息损失 |
| 装备碾压技能 | 强度系数锚定，且 Boss 门槛要求三者齐备 |
| 主包体积 | 零贴图（人形图矢量 + 着色），体积零增加 |
| 传说隐藏造型复杂 | 复用现有阶段模型机制 + Canvas 特效叠加，不新增资源 |
