1. 软件概述

1.1 软件基本信息

- 软件全称：动物大战外星军团游戏软件 - 软件简称：动物守卫战 - 版本号：V1.0 - 软件类别：休闲动作 Roguelike 动作游戏软件 - 著作权人：申请人（开发者本人） - 开发完成日期：2026年11月05日 - 适用平台：微信小游戏、移动端浏览器及跨平台 Web 环境

1.2 开发背景与设计目标

随着移动互联网与碎片化娱乐需求的增长，玩家对轻量化、高爽感、富有策略深度的动作 Roguelike 游戏表现出极高热情。本项目旨在研发一款以“萌系动物对抗外星异形虫潮”为世界观题材的高性能割草肉鸽游戏软件。

本软件立足于“零门槛上手、深度策略构筑、极致丝滑流畅”的设计理念，攻克了移动端小游戏在面对同屏千级实体碰撞时的卡顿与发热痛点，结合深度魔兽职业技能机制与五行元素相生流派，为用户提供沉浸式的割草解压体验。

1.3 核心功能概要

1. 多元角色与职业谱系：内置 5 大动物灵兽、12 大深度进化职业以及 7 阶外观动态蜕变体系； 2. 独特隐藏职业唤醒链：初始限定 3 大职业，每使用全新“种族×职业”通关组合即可依次唤醒九大隐藏职业； 3. 空间哈希物理碰撞：通过 80px 空间哈希网格算法实现千级单位毫秒级索敌与碰撞计算； 4. 五行八卦元素联动：覆盖金、木、水、火、土五行元素属性共鸣协同，激发全屏复合元素爆炸； 5. 16 部位全装甲穿戴：头盔、肩甲、武器、饰品等 16 个独立装备槽位，结合 5 级品质梯度； 6. 动态心流波次时间轴：15 分钟战局周期，前慢后密，并在 600 秒后进入高压“修罗场”模式； 7. 全域成就与云端漫游：40+ 细分成就项，支持本地毫秒级持久化与微信云数据库异步无缝漫游。

2. 运行环境与安装配置

2.1 硬件环境要求

- CPU 处理器：主频 1.5GHz 及以上（四核或以上移动端 / PC 处理器）； - 运行内存（RAM）：移动端 2GB 及以上，PC 端 4GB 及以上； - 显示分辨率：自适应主流移动屏幕分辨率（推荐 375×667、390×844、414×896 等各类全面屏与折叠屏）； - 网络连接：支持离线单机运行；联网状态下支持云端成就与存档漫游。

2.2 软件与系统要求

- 移动操作系统：Android 8.0 及以上版本 / iOS 12.0 及以上版本 / HarmonyOS 2.0 及以上版本； - 客户端环境：微信移动客户端 8.0.0 及以上版本； - 基础库要求：微信小游戏基础库版本 3.0.0 及以上； - 图形管线支持：支持 HTML5 Canvas 2D 渲染上下文，支持硬件加速。

2.3 开发与编译环境

- 开发工具：微信开发者工具 (WeChat DevTools) Stable v1.06+； - 代码运行时：Node.js v18.0.0 及以上； - 编程规范：ECMAScript 6 (ES6+), 原生模块化 (ESM)； - 构建机制：微信开发者工具内置 Babel 编译器转译，支持 ES6 语法增强与代码混淆压缩。

2.4 安装与部署启动流程

1. 获取工程源代码：将工程根目录导入本地工作区（包含 `game.js`、`game.json`、`project.config.json` 及 `js/` 核心逻辑目录）； 2. 配置微信小游戏工程：在微信开发者工具中选择“导入项目”，目录指向工程根目录，填入合法 AppID 或选择“测试号”； 3. 编译与预览：点击开发者工具顶部的“编译”按钮，模拟器即刻自动加载进入选人界面； 4. 真机调试与上线发布：点击“预览”或“真机调试”，手机扫描二维码即可在真机微信环境启动体验；点击“上传”提交审核即可完成发布部署。

3.1 总体逻辑分层架构

【系统架构流程图】详见架构设计规范图表

3.2 核心数据流转模型

1. 输入采集：用户通过屏幕触控虚拟摇杆，`Joystick` 模块将触控偏移量转化为二维归一化方向向量； 2. 位移与物理计算：`Player` 消费移动向量并在世界坐标系中位移，`SpatialHashGrid` 实时注册玩家与敌人物理包围盒； 3. 技能自动索敌与释放：`SkillManager` 定时轮询冷却完毕的主动奥义，自动拾取空间哈希内最近敌人目标发射弹幕； 4. 命中与伤害事件分发：伤害计算模块结合暴击率与元素共鸣乘数计算最终净伤害，通过 `eventBus` 广播击中与击杀事件； 5. 数值反馈与状态持久化：`Enemy` 死亡生成 `Gem` 经验球与装备掉落，玩家拾取升级后触发持久化写入与成就检查。

3.3 零 GC 高性能对象池架构

为杜绝移动端由于高频发射子弹和击杀怪物产生的内存碎片与垃圾回收 (GC) 停顿，系统核心组件全面落地对象池设计： - 投射物对象池：旋风斩残影、火球术飞弹、冰环等粒子特效在消失后不执行内存销毁，而是重置属性后压入 `Pool` 缓存队列； - 怪物实体对象池：不同类型的外星普通虫怪、快速酸液虫、自爆异形使用专用回收链表，下一波生成时直接唤醒复用； - 浮动文字与特效池：跳字与命中火花统一由循环队列管理，固定上限，严控内存开销在 60MB 以内。

3.4 纯 Canvas 2D 矢量降级渲染管线

系统内置了革命性的无图降级渲染管线（`modelStage.js`）： - 全矢量图形绘制：当外部美术贴图未加载或低网络环境下，系统无缝调用底层 Canvas 2D 路径绘制指令； - 分层粒子与光效：从 1 阶初心幼体到 7 阶至尊天神，通过多重旋转矩阵、半透明渐变、金芒披风与神力光环动态组合出炫酷外观； - 首屏秒开：无需等待外部数十兆立绘图片下载解码即可即刻开战，大幅提升弱网机型的留存率。

4. 核心功能模块详细操作指南

4.1 灵兽角色与血脉选择模块

- 功能界面说明：进入游戏首屏呈现“灵兽血脉选择”舞台。界面罗列五大经典灵兽动物（狂暴母鸡、嘎嘎神鸭、蛮荒铁牛、圣光毛毛羊、无敌咸鱼王）。 - 操作方式： 1. 点击顶部左右滑动栏中的灵兽卡牌，中心舞台即刻切换展示该灵兽的 3D 悬浮透视立绘； 2. 下方属性卡动态呈现该灵兽的专属血脉特性（如小鸡受惊疾跑、神鸭自带 15% 闪避、铁牛自带 15% 免伤、咸鱼王血量低于 50% 爆发狂怒）； 3. 确认选定当前动物后，点击底部金色发光按钮 “确认【灵兽名】· 前往觉醒职业 ➔” 进入职业配置阶段。

4.2 职业卍解与隐藏职业觉醒模块

- 功能界面说明：顶部呈现当前选定灵兽的胶囊导航，支持随时点击“◂ 重选灵兽”回退。中部网格平铺展示 12 大进阶进化职业。 - 职业解锁规则与界面反馈： 1. 初始三大职业开放：狂暴战神、神圣骑士、奥术法师默认处于点亮可用状态； 2. 九大隐藏职业视觉：未解锁职业卡牌呈现深黑半透明色调、剪影淡化并悬浮显目金色锁头 🔒 标识； 3. 出战防作弊拦截：点击未解锁职业卡片时，底部开启战役按钮自动禁用并置灰，提示 “🔒 隐藏职业未觉醒 · 需新组合通关解锁”，阻断非法开启； 4. 通关觉醒动态徽章：若选择已解锁职业搭配当前灵兽，系统自动检测历史通关档案： - 若为未曾通关过的新组合：详情面板顶部高亮闪烁 “✨【全新组合】通关本局可解锁下一个隐藏职业！”； - 若为已通关组合：展示 “🏆【已通关组合】此组合已记入通关档案”； 5. 点击底部 “确认部署 · 踏上征途 ⚔️” 正式开战。

4.3 实时战斗操控与物理碰撞模块

- 操控操作： - 屏幕任意区域支持单指触摸激活全向虚拟摇杆（`Joystick`），滑动即可控制灵兽进行 360 度灵活走位； - 放开手指灵兽即刻原地驻留，施加惯性阻尼刹车，操作手感极佳； - 战斗机理： - 自动锁敌：玩家无需繁琐对准瞄准，系统内置的近邻索敌算法自动朝攻击范围内最具威胁的外星怪物施放技能； - 动态避障与碰撞：敌人成群结队向玩家聚拢，撞击玩家将扣除血量并触发屏幕红色闪烁与震屏反馈（Screen Shake）。

4.4 技能进阶与命运三选一构筑模块

- 经验收集：击杀外星怪物掉落璀璨灵魂经验水晶（Gem），玩家靠近自动产生磁力吸附入体； - 三选一领悟界面： 1. 经验槽满额后，游戏画面平滑进入暂停时空，中央弹出三张充满悬念的“命运绝学”塔罗卡牌； 2. 卡牌展示技能派系（战斗、神圣、邪能、死亡、奥术）、自然属性（金木水火土）、技能效果与当前升级等级； 3. 防误触保护：弹出瞬间设置 500ms 凝神感悟锁，防止玩家剧烈滑动摇杆时误触选定不心仪技能； 4. 极境突破机制：灵兽专属本命技能可打破常规 5 级上限，成功突破至 【Lv.6 神话极境】，获得全屏毁天灭地特效。

4.5 16 部位全武装装备穿戴模块

- 部位清单：涵盖主手神兵、副手盾牌、头盔、胸甲、肩铠、护腕、手套、腰带、腿甲、战靴、项链、戒指、护符、披风、图腾、法宝共计 16 大部位； - 品质梯度：普通（白）、优秀（绿）、精良（蓝）、史诗（紫）、传说（金）； - 操作与掉落：击败精英怪物或首领 Boss 掉落宝箱装备，战利品即时自动装配，属性自动聚合提升生命上限、移速、暴击与免伤率。

4.6 五行元素属性协同增伤模块

- 技能与装备深度附带 金 (METAL)、木 (WOOD)、水 (WATER)、火 (FIRE)、土 (EARTH) 五行属性； - 当玩家在当局战局中同时掌握特定属性组合时（例如水 + 火产生【水火交融·蒸发狂暴】，金 + 雷产生【金雷合鸣·电弧传导】），自动触发全屏元素羁绊，输出攻击力大幅跃升 25% ~ 60%。

4.7 动态心流波次与时间轴难度调控

系统通过严格的 15 分钟（900 秒）全局时间轴管理战斗节奏： - 0 ~ 180s（开局发育期）：怪物生成节奏缓和，单体血量与攻击略高，考验走位；经验爆率高，助玩家快速领悟初始奥义； - 180 ~ 450s（中期爬坡期）：生成密度提升，引入快速突进虫与远程酸液异形； - 450 ~ 600s（后期割草期）：海量群聚异形蜂拥而至，单体相对变脆，玩家 AoE 技能成型，体验极致清屏割草快感； - 600 ~ 810s（修罗场高难演进）：难度陡增（Spike Escalation），怪物速度提升 25%、攻击力暴涨，检验玩家综合构筑与走位极限； - 810s（第 13.5 分钟）：终极首领 【深渊大恶魔·玛洛诺斯】 携漫天烈焰流星降临，开启终章弑神对决。

4.8 角色 7 阶外观视觉蜕变演化模块

玩家从 1 级成长至 60 级满级，外观模型层层演变： - Stage 1 (1~9级) 初心幼体：原始基础萌系轻装； - Stage 2 (10~19级) 见习勇士：佩戴初级战盔，武器散发微白微光； - Stage 3 (20~29级) 精锐武者：单侧轻型肩铠具象化，神兵初现轮廓； - Stage 4 (30~39级) 重装大师：双侧重铠与背部微型光翼舒展； - Stage 5 (40~49级) 史诗宗师：专属神器在手，半透明元素能量光羽流转； - Stage 6 (50~59级) 神话领主：全身战铠流光环绕，脚底浮现动态旋转六芒星法阵； - Stage 7 (60级满级) 至尊天神：粒子风暴环绕、璀璨天神之翼、耀眼金色首领神环。

4.9 全域成就与多端云档漫游模块

- 成就分类：划分为战斗杀敌、成长之路、通关征服、构筑大师、全图鉴、装备收藏等 6 大分类，共计 40+ 深度成就项； - 成就奖励：达成指标不仅获得专属霸气称号（如“星界屠神”、“天命神选”、“武装大师”），还享有额外通关积分加成； - 多端漫游：自动接入微信云数据库，换机登录自动增量合并本地与云端进度，保障数据万无一失。

4.10 远征大捷结算与丰碑战报模块

- 胜利界面：击败最终恶魔首领后，弹出金碧辉煌的“远征大捷·丰碑战报”； - 数据统计：汇总玩家本局存活时长、斩落外星怪数量、角色最终造诣形态、技能搭配评级（S+ 极境破限等）及装备总战力评分； - 觉醒横幅盛典：若当局以新组合取胜并解锁了新隐藏职业，屏幕中央盛大展开 “🎉【新职业觉醒】唤醒全新隐藏职业：[职业名]！” 金色勋章； - 点击底部“再次出征·重新开始”一键重置战场，开始全新轮次的远征。

5. 性能优化与安全可靠性保障

5.1 屏幕高刷新率与 DPR 动态自适应

针对移动设备屏幕物理像素与 CSS 逻辑像素不一致问题，系统通过 `window.devicePixelRatio` 动态调整离屏/上屏 Canvas 画布尺寸，字体与微小粒子均以超高清物理分辨率栅格化渲染，彻底消除文字虚边模糊。

5.2 触控防抖与长按误触拦截

游戏内所有交互按钮均设置触控防抖时间窗口与滑动距离判定，有效过滤用户因手汗滑动、多点触碰引起的误判，确保操作指令百发百中。

5.3 数据多重校验与本地防篡改

所有存档指标均通过专用 JSON 字段封装，读取过程内置键值存在性与数字范围校验，防止因存储异常导致的数值越界或游戏崩溃。

6. 常见故障排查与技术支持

6.1 常见运行问题与解决方案

1. 黑屏或未响应：检查微信版本是否为 8.0 以上；清理微信本地缓存后重新进入； 2. 画面轻微发热：软件已开启对象池与无图降级模式；若低端设备发热，可在设置中调低粒子特效等级； 3. 存档未同步：确认微信小游戏网络授权已开启，软件会在联网瞬间自动将本地通关成就增量回传云端。

6.2 版本维护与服务支持

- 当前软件版本：V1.0 - 技术支持维护：团队持续跟踪微信底层基础库升级，定期更新优化物理引擎效率与全新拓展职业。
